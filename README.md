# Portfolio — Rajan Kumar

Personal portfolio site for **Rajan Kumar**, Senior Frontend Developer.

🌐 **Live:** [https://rksperax.github.io](https://rksperax.github.io)

## Stack

- Static HTML + CSS
- Hosted on GitHub Pages (`rksperax.github.io` repo)

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080)

## Deploy

Push to `main` — GitHub Pages publishes automatically.
